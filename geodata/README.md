# Happ geodata

`happ-geosite.dat` and `happ-geoip.dat` are generated by
`.github/workflows/build-custom-mrs.yml` from:

- the public `runetfreedom/russia-v2ray-rules-dat` release data;
- `rules/custom_proxy.txt` and `rules/custom_local.txt` from this repository.

The output keeps only the tags used by the DHQ Happ profile:

- `dhq-proxy`: `ru-blocked` + re:filter + custom PROXY rules;
- `dhq-direct`: custom DIRECT rules;
- `dhq-block`: `category-ads-all`;
- `category-ru`, `ru`, and `private` for direct routing.

The runetfreedom source is distributed under GPL-3.0. The generated geodata files
are distributed under the same terms; this directory and the public workflow are
the corresponding build source. `geomixer`, used only as the build tool, is MIT.
